# Subscription-Management-System

Short Summary of the Problem Statement

Brightloop Software currently manages subscriptions, renewals, invoices, payments, and revenue reports manually using spreadsheets and other manual processes. This leads to missed renewals, billing errors, and poor visibility of revenue. 

The goal is to build a Subscription Management System that brings the entire process into one platform—from creating plans and subscriptions to automatically generating invoices, recording payments, and tracking revenue. 

In one line:

Automate the complete subscription and recurring billing lifecycle in one unified system.
